# Volcano Weather System

Volcano monitoring app: Laravel 13 + Inertia React SPA + companion Python FastAPI service.

## Architecture

- **Laravel app** (PHP 8.3): Inertia v3 + React 19, Tailwind v4, Leaflet maps, Wayfinder typed routes
- **Python service** (`python-service/`): FastAPI + SQLAlchemy, connects to MySQL `db_weather_sistem` (separate from Laravel's SQLite dev DB)
- **8 models**: Volcano, Eruption, AshPrediction, WeatherForecast, WeatherObservation, WindObservation, AshAdvisory, User
- **3 API controllers**: `MonitoringController`, `VolcanoController`, `GeoHazardController` — mounted in `routes/api.php`
- **Web routes** (`routes/web.php`) render Inertia views directly (no controllers)
- **VAAC Darwin pipeline**: `vaac_collector.py` parses BOM volcanic-ash advisories (UTC→WIB, FL→m) → `vaac_job.py` upserts into `ash_advisories` keyed by `(volcano_id, issued_at)` → `MonitoringController` exposes latest advisory; frontend panel in `Monitoring.tsx`

## Key Commands

Note: `.npmrc` sets `ignore-scripts=true` — postinstall hooks are suppressed.

```bash
composer setup          # install + migrate + npm install + build (full fresh setup)
composer dev            # runs `php artisan dev` (Vite + queue + schedule in one process)
composer lint           # Pint formatter (fix mode)
composer lint:check     # Pint dry-run
composer types:check    # PHPStan level 7
composer test           # config:clear → lint:check → types:check → artisan test
composer ci:check       # npm check → npm types:check → artisan test (mirrors CI)

php artisan test --compact                                  # run all tests
php artisan test --compact tests/Feature/MonitoringTest.php # single file
php artisan test --compact --filter=testName                # by name

DANGER: `php artisan test` wipes the MySQL dev DB (`volcanoes`/`eruptions` gone) if
`bootstrap/cache/config.php` exists — cached config makes RefreshDatabase run
`migrate:fresh` on MySQL. ALWAYS run `php artisan config:clear` before raw
`php artisan test`, or use `composer test` which clears config itself.

npm run check      # vite-plus lint (JS/TS)
npm run check:fix  # vite-plus lint fix
npm run types:check # tsc --noEmit
```

## CI

Single workflow (`.github/workflows/tests.yml`): runs on push to `main` and all PRs.
Steps: checkout → PHP 8.3 setup → Node 22 setup → `composer setup` → `composer ci:check`.

## Generated Code — Do Not Edit

These directories are auto-generated by Wayfinder and Vite plugin. Overwrites will be lost:

- `resources/js/actions/**` — typed controller action stubs
- `resources/js/routes/**` — typed route helpers
- `resources/js/wayfinder/**` — Wayfinder internals
- `resources/js/components/ui/**` — shadcn/UI components (if present, not currently installed)

## Formatting

- **PHP**: Pint with `laravel` preset. Run `vendor/bin/pint --dirty --format agent` after PHP changes.
- **JS/TS/CSS**: vite-plus built-in formatter (Prettier-based). Configured in `vite.config.ts` under `fmt`. 4-space indent, single quotes, 80 print width.
- **EditorConfig**: LF line endings, UTF-8, 4-space indent.

## Testing

- **Pest v4** with `RefreshDatabase` on Feature tests.
- Tests run against **in-memory SQLite** (configured in `phpunit.xml`).
- Create tests: `php artisan make:test --pest {Name}` (omit suite directory prefix).
- Use model factories. Check for custom states before manual setup.

## Python Service

- Entry: `python-service/app/main.py` (FastAPI, port 8000 default)
- Config: `python-service/app/config.py` reads MySQL env vars from `python-service/.env`
- Contains collectors, jobs, models, and scheduler — a data pipeline for volcano/weather data
- Activate venv before running: `python-service/venv/`
- Scheduler (`scheduler.py`) runs `run_all_jobs()` every 10 minutes: volcano activity → VAAC advisory sync → BMKG weather forecast → ash prediction generation
- Missing dependency: `beautifulsoup4` is imported by collectors but not in `requirements.txt`

## Frontend Notes

- Entry: `resources/js/app.tsx` → `createInertiaApp` from `@inertiajs/react`
- Pages: `resources/js/pages/` (currently `welcome.tsx`, `Monitoring.tsx`)
- Map components use Leaflet (`react-leaflet`): `VolcanoMap.tsx`, `WindyMap.tsx`
- TypeScript path alias: `@/*` → `resources/js/*`
- React Compiler enabled via babel plugin in `vite.config.ts`
- Monitoring.tsx uses client-side `fetch()` to API routes, not Inertia page props
- If Vite manifest error occurs: run `npm run build` or `composer dev`
